Yoww 备份拼合工具

把云端备份的碎片拼回一个完整的 zip。全程在你自己的设备上完成，不会上传到任何地方，断网也能用。

1把备份文件夹整个下载下来

到你的 GitHub 备份仓库 → yoww-backup 文件夹。仓库首页右上角 Code → Download ZIP 是最省事的，下完解压。

里面应该有一个 manifest.json 和若干个 chunk-000.bin、chunk-001.bin…

2把这些文件全都拖进来

拖文件到这里 或者点这里选择 · 把 manifest.json 和所有 chunk 一起选上

3拼合并下载

等着你先把文件放进来。

拿到 zip 之后怎么用：回到 Yoww → 我的 → 我的仓库 → 右上角齿轮 → 导入备份，选这个 zip 就行。

如果 Yoww 已经打不开了：这个 zip 用任何解压软件都能打开。items.json 是你所有条目的记录（类型、描述、链接、分类都在里面），blobs/ 里是缓存过的原件（表情、头像、字体文件、铃声都在这儿），文件名对应 items.json 里的 id，真实格式看 manifest.json 的 blobTypes。
